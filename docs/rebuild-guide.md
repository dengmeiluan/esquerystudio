# 重建与迁移选型指南

> 控制台「rebuild」分组有四页：托管重建、Reindex 高级、Reindex 预估、跨集群迁移。它们都能「把数据搬到另一个索引/集群」，但安全边界与适用场景不同——本文回答一个问题：**你的这次数据变动，应该用哪一页。**

## 决策表：我想……→用哪页

| 我想…… | 用哪页 | 页内路由 |
|---|---|---|
| 生产在跑的索引要改 mapping/settings，且不能停写 | 托管重建 | `/adhoc-rebuild` |
| 要零停机：全量搬完后自动追平增量，再原子切别名 | 托管重建（INCREMENTAL 增量追平） | `/adhoc-rebuild` |
| 要写阻断保证新旧索引严格一致，能接受短暂写入失败 | 托管重建（WRITE_BLOCK 写阻断窗口） | `/adhoc-rebuild` |
| 要自己决定别名切换时机，切换前人工放行 | 托管重建（切换前确认门，作业停在 `AWAIT_CONFIRM`） | `/adhoc-rebuild` |
| 把业务代码里的期望 mapping/settings 贴进来对差异后重建 | 托管重建（粘贴期望配置 + diff 审编） | `/adhoc-rebuild` |
| 大索引动手前先掂量数据量与磁盘，不写入任何数据 | Reindex 预估 | `/reindex-preview` |
| 一次性数据搬运，我要自由 body、全参数（slices / 限流 / scroll / remote 源） | Reindex 高级（Power Mode） | `/reindex-advanced` |
| 跨集群搬运，且目标集群已把源集群加入 `reindex.remote.whitelist` | Reindex 高级（remote 源直连） | `/reindex-advanced` |
| 整索引跨集群搬家，两集群间**没有** remote whitelist | 跨集群迁移 | `/xmigrate` |
| 跨集群搬运量大/周期长，中途要能暂停、断点续跑 | 跨集群迁移（`INTERRUPTED` 续跑） | `/xmigrate` |

## 长操作与预算（页面 / MCP 同口径）

- 结构同步、智能同步、按计划重跑、等价性验证在页面等待上限为 **3 分钟**；等待期间出现「停止等待」，只中止本次页面等待，并如实提示「服务端可能仍在执行」——它不等于取消服务端写入。
- 真正要停掉生产侧写入，用 MCP 的 `tasks/cancel`（批量写走 ES 异步端点，会对 `node:num` 下发 `_tasks/{id}/_cancel`）或迁移作业的 `abort`；页面「调用任务」条可直接取消 MCP 长调用。
- 保存过的同步计划在结构同步卡下方列出（源→目标、结构/增量、已跑次数），可复制 planId 或二次确认后重跑；源结构漂移会被 409 `PLAN_DRIFT` 拒绝。

## 能力对照表

| 能力 | 托管重建 | Reindex 高级 | Reindex 预估 | 跨集群迁移 |
|---|---|---|---|---|
| 追平策略 | 三选一：INCREMENTAL / WRITE_BLOCK / MANUAL | 无（一次 reindex，增量自理） | —（只读） | 无（一次搬运，增量自理） |
| 别名原子切换 | 有；可在切换前停 `AWAIT_CONFIRM` 等人工确认 | 无 | — | 无 |
| 配置校验 | 三层校验 + ES dry-run 实测，不过不放行 | 不设校验/幂等 | 不适用 | 不设 |
| 分布式锁 | 有（跨实例互斥；未生效会在页内亮黄提示） | 无 | — | 无 |
| 跨集群 | 否（本集群内重建） | 有：`source.remote` 直连，需目标端 whitelist | 否 | 有：服务端 scroll + bulk |
| 参数自由度 | 向导收敛，暴露必要项 | 自由 body，全参数（slices / requests_per_second / scroll / timeout / wait_for_active_shards / op_type / conflicts / version_type） | 仅 source 与可选 query | 并行路数 / 批大小 / scroll 保活秒 |
| 暂停 / 续跑 | 切换前确认门（`AWAIT_CONFIRM`） | 无 | — | 中止 / 断点续跑（`INTERRUPTED`） |
| 预估 | 确认预览步内嵌目标磁盘占用预估（失败静默降级，不阻断） | 无 | 主职：文档数 + 目标体积 + 建议批大小 | 无 |

## 托管重建（`/adhoc-rebuild`）

### 何时用

生产在跑的索引要改 mapping 或 settings，且不能停写。托管重建是四页里唯一把「审配置 → 搬数据 → 追增量 → 切别名」编成一个受控作业的入口：配置先过校验、增量有策略收敛、切换有确认门、全程有分布式锁互斥。

### 怎么进入

控制台侧栏「重建」分组 → **托管重建**；或直接访问 `/adhoc-rebuild`。业务侧从 Mapping 冲突转重建的路径见 [Mapping 指南](integration/mapping.md#mapping-冲突转-adhoc-重建)。

### 关键概念：三种追平策略

全量 reindex 期间业务还在往旧索引写——这段增量怎么补，是三策略的分野：

- **A · INCREMENTAL 增量追平**：必须指定 `timeField`（时间字段）。按它做 range reindex 收敛全量期间的增量，追到只剩一个小缓冲窗口（页内可调追平缓冲）。**语义前提**：文档写入时间可由该时间字段刻画；索引没有时间字段候选时此策略直接不可用，请改用 B 或 C。
- **B · WRITE_BLOCK 写阻断窗口**：切换窗口内对旧索引挡写，保证新旧严格一致。代价是这段时间业务写入持续失败；若未指定时间字段，则**全程挡写**（页内会要求显式勾选「接受全程挡写」）。适合能接受短暂写入失败的窗口期切换。
- **C · MANUAL 直切 + 回补**：不追平、不挡写，直接切别名，页内产出回补报告。**回补是人的责任**：切换瞬间前后的增量由你决定怎么补（时间字段 range、双写、业务重放均可）。

### 关键概念：确认门与分布式锁

- **切换前等待人工确认**：勾选后作业停在 `AWAIT_CONFIRM`，翻别名前必须人工放行。此刻若是 WRITE_BLOCK，挡写已在进行、业务写入持续失败，页内会醒目标出。确认门有竞争与超时语义：超时方自动解除写阻断、不执行切换。
- **分布式锁**：同一索引的重建跨实例互斥。锁未生效（未启用或未抢到）时页内亮「锁保护未生效」黄标，提示确认没有其他实例在同时重建同一索引。

### 五步概述

1. **选索引** —— 先选源索引，再贴/编配置；可粘贴期望配置。
2. **审编 settings / mapping** —— 双 Tab 编辑器编辑期望值，页内给出与现役配置的 **diff**，配置差异逐行过目；含 date 兼容风险报告。
3. **追平策略** —— 三选一（见上）；INCREMENTAL 必选时间字段，无候选时该策略置灰并说明原因。
4. **确认预览** —— 汇总目标索引名、策略、时间字段与缓冲、确认门档位；内嵌**三层校验 + ES dry-run 实测**（不过不放行，dry-run 实测目标集群也会显示，打偏集群一眼可见）；同屏给出**目标磁盘占用预估**（估算失败静默降级为不显示，不阻断预览）。
5. **执行监控** —— 全量 reindex 进度、追平阶段、`AWAIT_CONFIRM` 阻断横幅、原子别名切换与回补报告，同一时间线呈现。

## Reindex 高级（`/reindex-advanced`）

### 何时用

懂 ES 的老手做一次性数据搬运：要自由 body、全参数调优，或要跨集群 `reindex.remote` 直连。页面明确标注 **Power Mode——不设幂等 / 自动校验的原生入口**：目标索引、`dest.op_type` / `conflicts` / `version_type` 完全交由用户控制，出了边界问题页面不兜底。

### 怎么进入

控制台侧栏「重建」分组 → **Reindex 高级**；或直接访问 `/reindex-advanced`。

### 关键概念

- **本地 / 远程源**：源可切「本地」或「远程集群」。远程源走 `source.remote`，**前提是目标集群已把源集群地址加入 `reindex.remote.whitelist`**——没有 whitelist 就走不通，改用跨集群迁移。
- **全参数**：`slices`（并行切片）、`requests_per_second`（限流，`-1` 不限）、`scroll`（保活）、`timeout`、`wait_for_active_shards` 等逐项可调，带输入校验与中文释义。
- **自由 body**：最终请求体可直接编辑，页面不做语义校验——这是它与托管重建的根本区别。

## Reindex 预估（`/reindex-preview`）

### 何时用

动手前掂量数据量与磁盘：**只读**，仅调用 `_count` + `_stats`，不写入任何数据。

### 怎么进入

控制台侧栏「重建」分组 → **Reindex 预估**；或直接访问 `/reindex-preview`。

### 关键概念

- **可带 query**：预估可附带一个查询体，只算命中子集的量——适合「按条件归档/瘦身前先看规模」。
- **输出**：文档数、目标体积（经验公式估算）、建议批大小；目标体积超 50GB 时明确提示先增大目标索引的主分片数。

## 跨集群迁移（`/xmigrate`）

### 何时用

整索引跨集群搬家，且两集群间**没有** remote whitelist（或不想动目标集群配置）。搬运由服务端执行 scroll + bulk：关掉页面任务仍在服务端跑，凭据由服务端从**连接中心档案**取用，明文不经前端。

### 怎么进入

控制台侧栏「重建」分组 → **跨集群迁移**；或直接访问 `/xmigrate`。

### 关键概念

- **凭据边界**：源/目标集群凭据走连接档案；也支持 `${ENV_VAR}` 引用服务端环境变量，仅在内存流转、绝不持久化。
- **暂停 / 续跑**：作业可中止；中止、失败或中断后状态为 `INTERRUPTED`，可断点续跑（续跑时需重新供给旧集群凭据）。已写入目标的数据保留，不从头再搬。
- **调优项**：并行路数（sliced scroll）、批大小、scroll 保活秒，均有服务端默认值。

## 页间重叠时的取舍

- **托管重建 vs Reindex 高级** —— 安全编排 vs 自由度。托管重建用向导换确定性：配置校验、追平策略、确认门、分布式锁、原子切换都是页内编排好的；代价是参数面收敛、body 不自由。Reindex 高级正好相反：全参数、自由 body、remote 直连，但没有校验、没有幂等、没有切换编排。能走托管的场景优先托管；只有当你要的形状（op_type、conflicts、version_type、remote）超出向导表达范围，才落到高级。
- **跨集群迁移 vs Reindex 高级 remote** —— 有没有 whitelist。目标集群能加 `reindex.remote.whitelist`、想让 ES 自己搬，用高级页的 remote 源，一条 `_reindex` 完事；加不了 whitelist（或两端都动不了配置），用跨集群迁移页，由本控制台服务端 scroll + bulk 中转。前者少一跳、无中转凭据；后者不挑集群配置、可暂停续跑。
- **Reindex 预估 vs 托管重建的内置预估** —— 同一估算端点的两种用法。托管重建的确认预览步内嵌了目标磁盘占用预估，复用的就是预估页的 `reindex-preview` 端点（浏览器模式同构），但作为增强信息失败时静默降级。需要**可带 query 的独立掂量**、或要在动手前反复试算不同子集的规模，用预估页；已经在向导里走到第 4 步，直接看内嵌那行即可，不必跳页。
